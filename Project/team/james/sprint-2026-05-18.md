### Task T6: MainViewModel `MarkAsSpamCommand` + `NotSpamCommand`
**Files:**
- `src/GreatEmailApp/ViewModels/MainViewModel.cs` (existing — add two new `[RelayCommand]` methods near `JunkAsync` at line ~650)
**What the problem is:** No command exists that combines "move to Junk" + "add sender to BlockedSenders" + "save config." Same on the inverse side.
**What to build:**
1. `[RelayCommand] private async Task MarkAsSpamAsync(MessageViewModel? m)`:
   - Resolve account + creds same as `JunkAsync`
   - Read current `App.SpamConfig.Load()`
   - If `m.SenderEmail` is non-empty AND not already in `BlockedSenders`: append it (case-insensitive dedupe)
   - Save config back via `App.SpamConfig.Save(cfg)`
   - Call `MoveToSpecialAsync(m, SpecialFolder.Junk, "Marked as spam")` (existing helper)
   - Status message: `"Blocked {sender} and moved to Junk."`
2. `[RelayCommand] private async Task NotSpamAsync(MessageViewModel? m)`:
   - Same shape, but operate on `TrustedSenders` (add) AND `BlockedSenders` (remove if present)
   - Move message back to `SpecialFolder.Inbox` (need new `MoveToSpecialAsync` overload OR use `MoveToFolderAsync` with the explicit Inbox path)
   - Status message: `"Trusted {sender} and moved to Inbox."`
3. Both commands trigger an immediate `_serverSearchActive = false` and folder reload so the moved message disappears from the list.
**Dependencies:** None — `App.SpamConfig` already exists (Phase 1).
**Estimated effort:** 2 hr.
